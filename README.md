## Acerca de este Proyecto

Portafolio personal desarrollado con React.js que muestra mis proyectos, habilidades y experiencia como desarrollador Full Stack.

## Construido Con

Mi portafolio personal que presenta mis proyectos de GitHub, así como mi currículum y habilidades técnicas.<br/>

Este proyecto fue construido usando las siguientes tecnologías:

- React.js
- Node.js
- Express.js
- CSS3
- VsCode
- Vercel

## Características

**📖 Diseño Multi-Página**

**🎨 Estilizado con React-Bootstrap y CSS personalizable**

**📱 Totalmente Responsivo**

**🌐 Completamente en Español**

## Comenzando

Clona este repositorio. Necesitarás `node.js` y `git` instalados en tu máquina.

## 🛠 Instrucciones de Instalación y Configuración

1. Instalación: `npm install --legacy-peer-deps`

2. En el directorio del proyecto, ejecuta: `npm start`

Ejecuta la aplicación en modo de desarrollo.\
Abre [http://localhost:3000](http://localhost:3000) para verlo en el navegador.
La página se recargará si realizas ediciones.

## Instrucciones de Uso

Abre la carpeta del proyecto y navega a `/src/components/`. <br/>
Encontrarás todos los componentes utilizados y puedes editar tu información según corresponda.
